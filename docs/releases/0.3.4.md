# card-glint 0.3.4

The Magic pack restores colored panels and large mana symbols on ordinary modern
basic lands. The frame palette follows the basic-land subtype while explicit
frame colors and custom rules remain authoritative. This works across ordinary
modern component frames and the existing Eighth/M15 plate painters.

Ordinary modern cards now include collector numbers, rarity and small-cap artist
credits. Verified default copyright wording and printed set totals cover Eighth
Edition, Magic 2015, War of the Spark, Core Set 2021 and Foundations. Supplied legal
text takes precedence; other sets do not receive guessed copyright wording or
variant-inclusive set totals.

The ordinary art aperture follows each frame's horizontal resizing. A thin rim
surrounds all four sides instead of thick side strips with art covering the top
and bottom. M21 gains approximately three reference pixels of artwork width;
other frame geometries retain their existing scaling. Vertical aperture placement
remains a separate calibration item.

Starting loyalty and ability-cost numerals now use separate ink-centered layouts.
Starting loyalty is slightly smaller and sits below the shield notch; costs are
slightly larger, with distinct centers for plus, zero and minus badges. Across
11 normalized M15/M21/WAR examples, mean vertical lettering error within the black
body falls from 3.82 to 0.14 reference pixels for starting loyalty and from 1.53
to 0.47 for 29 measured costs. These are local calibration diagnostics, not
whole-card accuracy scores. Badge artwork and placement retain their own review
items.

Ordinary hologram mounts no longer leave a translucent white halo over colored
paper. The colored ring, opaque white pinline and oval artwork are preserved.
Preparation uses the existing bounded cache; animation adds no image decoding,
font loading or readback.

Public interfaces remain compatible. This patch does not require consumer input
changes. The public showcase continues to load only original repository assets.
