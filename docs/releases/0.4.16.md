# card-glint 0.4.16

Arabian Nights, Antiquities and The Dark now use shared set-specific
power/toughness placement, sizing and stroke weight. Filled light ink and a
separately thinned lower-right shadow replace the high, heavy default treatment.
Long expressions retain their natural width and align to a shared right edge.

Reviewed Antiquities originals restore Gaea's Avenger's `*+1/*+1` and
Shapeshifter's `*/(7-*)`. The renderer uses the font's visible long dash for
subtraction; its mathematical-minus glyph contains no ink. Source semantics and
Oracle values are unchanged. The public printing resolver retains the exact
printing and scan provenance of both corrections.

Native checks cover all 316 printings in this group: 144 change, 141 scored
candidates reproduce exactly, and no pixels change outside the stats region.
All 84 unrelated control cards remain identical. Host text-color and omission
controls continue to work. Preparation adds no per-frame decoding, font loading,
shader compilation or pixel readback.

On 306 accepted normalized scans, the existing whole-card structural index
improves from 74.13% to 75.64%; the stats-region index improves from 47.87% to
87.27% on 141 cards. These are similarity indices, not correctness percentages.
The validation names were previously inspected, so this is repeated validation.
The application metric's fixed stats crop does not cover the leading portion of
long expressions; fitting also used complete, input-derived crops.

Five stat-bearing scans remain excluded because their frame poses need review.
Two unsupported gold creatures in The Dark retain their previous treatment.
Grave Robbers remains a recorded placement outlier. The existing ink palette is
retained; this is not a new pigment calibration or completion of every set task.
Historical calibration receipts and the host-API compatibility checks remain
intact behind the independently verified stats update.
