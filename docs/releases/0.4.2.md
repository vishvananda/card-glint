# card-glint 0.4.2

This patch improves ordinary early-expansion frames and M21 black-frame color.
Existing consumer inputs remain compatible; no migration is required.

- Add 18 source-bound frame/geometry profiles for Arabian Nights, Antiquities
  and The Dark. Choose ABU or Fourth sources by material, fit their apertures,
  and recut outer stock independently. Unsupported variants retain prior pixels.
- Add 11 outer-frame and 15 rules-box color fits for those sources. Separate
  pigment, paper, texture contrast and stock; retain raw pigment for the ten
  rejected component fits. Preparation stays cached, outside animation frames.
- Across the 282 early-expansion scans with accepted interior normalization,
  the fixed regional structural index improves from about 42.5 to 62.8 out of
  100, with no per-card regression. All unverified type lines and fallback rules
  are excluded from the weighted index; 34 unresolved scans stay in the review
  queue. These development diagnostics do not certify full-card correctness.
- Reduce the green cast in ordinary nonlegendary M21 black frames. Median
  clear-rail color distance improves from 2.14 to 1.43 across 39 accepted scans;
  reserved names improve from 2.15 to 1.79. Forty cards change, while the other
  252 nonfoil M21 rasters and all artwork/paper probes remain identical.
  Legendary crowns, colored artifacts, planeswalkers and lands stay separate.
- Add a set-completion ledger covering 272 major sets and 16,716 variants, with
  18 explicit checks per variant. Existing profiles and unmeasured defaults are
  not automatically considered calibrated. Rejected fits, foil-only references,
  source changes, printing coverage and release status remain visible.
- Record scan-only affine normalization with independent boundary validation.
  M21 white/blue/black/green cover 163 accepted scans; Liliana's Scorn remains
  open. Red's apparently consistent poses fail a known scale/skew test and are
  not adopted. These local templates do not change renderer placement or update
  a hosted review service automatically.

Color measurements describe cached scans, not physical ink. Reference cohorts
were reused during development, and regional color distances are not whole-card
accuracy percentages. Typography, symbols, missing materials and rejected
normalizations remain open; no set is claimed fully calibrated. Alpha/Beta stock
policy, mana targets, other calibrated sources and public interfaces are preserved.

Validation includes strict Clippy, rustfmt, type and boundary checks, the Magic
accuracy suite, native rendering of all 316 early-expansion and 292 nonfoil M21
printings, package consumption, browser and local-only showcase tests. The public
showcase retains only original repository assets.
