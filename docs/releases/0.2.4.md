Artwork-only treatments now leave the showcase frame and symbols above the effect.

- Separate illustration and printing layers prevent rain/pool parallax from
  refracting the overlaid medallions, lettering and engraved frame.
- The new optional showcaseDocument helper demonstrates the existing layer API;
  the single-raster pack API remains compatible.
- Heat shimmer uses stronger, mainly horizontal softening.
- Rain has a little more condensation and softening behind the clear droplets.
- Tests cover opaque frame pixels within the artwork, all seven treatments,
  exports, overlays and cached scope changes.
