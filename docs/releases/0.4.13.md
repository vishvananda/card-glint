# card-glint 0.4.13

This patch calibrates original mana symbols for ordinary Arabian Nights,
Antiquities and The Dark cards. Shared set defaults correct placement, size,
spacing and numeral position. Color-specific glyph adjustments preserve the
mana circle, and printing calibration supplies fitted disc colors. Modern-symbol
choices retain their existing treatment. Public interfaces are unchanged.

Arabian Nights' dark variants use smaller, low-visibility generic circles and
the existing MPlantin font. Dagger-numbered light variants keep the larger
symbols. Unknown collector numbers retain the common style. Color fitting is
opt-in through printing calibration; the partial-alpha dark bubble is an
empirical approximation. Existing number and per-color glyph controls remain
relative to the printing defaults. Preparation reuses the existing bounded
caches; animation adds no font loads, decoding or readback.

The reviewed original wording resolver now returns two separate `{5}` symbols
for Arabian Nights' Aladdin's Lamp. Its Oracle cost remains `{10}`. This is an
exact-printing correction with scan provenance, also used by accuracy tooling.

Mana geometry and material fits use calibration cards with frozen independent
frame normalization. Native validation covers 189 reserved printings whose scans
have been inspected in earlier studies; these are repeated validation, not a
fresh holdout. Primary mana-region edge overlap changes as follows:

| Set            | Before | After | Improved validation printings |
| -------------- | -----: | ----: | ----------------------------: |
| Arabian Nights |  58.8% | 83.2% |                       46 / 46 |
| Antiquities    |  55.0% | 81.6% |                       59 / 59 |
| The Dark       |  58.4% | 84.7% |                       84 / 84 |

These are regional similarity diagnostics, not whole-card correctness
percentages. Both fixed comparison crops improve on every validation card.
Colored glyph fits also use filled-area masks at three thresholds; the Arabian
Nights white glyph adjustment was rejected, retaining its prior geometry.
Light-variant white and black color samples remain sparse. ARN/ATQ white
disc shade remains a review item: the native RGB cluster diagnostic regresses
slightly, by less than one RGB-distance unit.

All 316 set cards were replayed through the integrated painter. The 276 scored
cost renders reproduce their fitted candidates exactly. Changes on 288 cards
are confined to mana-cost areas and actual inline-symbol bounds; other card
components retain identical pixels. Eighty-four unrelated cards across twelve
sets also retain identical native PNGs.

The existing whole-card structural index rises from 71.5 to 74.1 across 306
accepted scan poses: 280 improve, 25 are unchanged, and Gaea's Touch declines
by 0.19 points. Its printed cost remains left of the shared set default, so it
stays a placement review item. These local diagnostics retain the existing
unverified-credit exclusion and do not update hosted accuracy graphs. The
Aladdin's Lamp comparison also includes its corrected printed cost.

Ten unresolved scan poses remain outside scoring. Artist-credit ink, remaining
text weight reviews, and incomplete frame groups remain open calibration work.
