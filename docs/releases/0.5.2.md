# card-glint 0.5.2

This release adds reviewed frame, color, mana, name, type, artist and power/
toughness calibrations for Fallen Empires, Fourth Edition and Chronicles.
These ordinary printings now use single-file calibration profiles, with a
contribution guide and reproducible validation/export tools. Rules/flavor,
expansion symbols and whole-set approval remain separately tracked work.

Non-Alpha cards use a common 0.045 corner radius. Alpha retains 0.058. Corner
silhouettes remain separate from the existing interior accuracy index; a
reviewed dependency receipt can reuse unchanged interior measurements while
new previews always render the current release.

The Magic pack exposes typed set calibration descriptors and revision-bound
candidates for its consolidated profiles. Candidates use the normal painter,
are scoped to a printing set and never mutate shared defaults. Hosts can render
and export one candidate profile without parsing source code. Unsupported frame
families report missing capabilities explicitly.

PR #7 adds native printing/coating resources and selective finish coverage to
`card-glint/finish`: `printDots`, `cardstock`, `documentCoverage`, `FinishMap`,
`PRINT_DOTS_GLSL` and `CARDSTOCK_GLSL`. Preparation returns portable resources,
keeps document work abortable and serialized, and performs no preparation in
an animation loop. Existing finish defaults and calling conventions are retained.
The public additions are backward compatible; this is a patch release.
