# card-glint 0.2.26

Revised dual lands now keep their dense original text size when the host chooses
centering based on Oracle wording. The short Oracle reminder previously selected
the larger basic-land layout for the original paragraph, crowding the type line.
The chosen wording still determines centering; the visible text determines size
and safe bounds.

All 25 Revised land printings were checked with original and Oracle wording under
all three alignment policies. Original-based scoring renders are pixel-identical
to 0.2.25. This fixes the alternate display option without changing the calibrated
printing layout, artwork, frame colors or source text.
