# card-glint 0.4.4

This patch improves ordinary M21 red-frame pigment and prevents Oracle fallback
in new original-text calibration inputs. Public renderer interfaces are unchanged.

- Fit one source-bound red pigment curve across 42 ordinary nonlegendary cards.
  Median frame-rail color error improves from 3.22 to 1.50; ten reserved names
  improve from 3.78 to 2.34. Every cohort passes both current-renderer and raw-source
  shadow, contrast, clipping and per-printing regression limits. These are Oklab
  color distances multiplied by 100, not whole-card accuracy percentages.
- Keep crown and paper profiles independent of the ordinary-frame correction.
  Replay all 292 ordinary nonfoil M21 cards with original rules in both versions:
  42 change and 250 stay identical. Central art, paper, outer stock and silhouette
  alpha are preserved. All 645 selector controls retain their mana/stock settings;
  601 unrelated material configurations are identical.
- Validate the unchanged ordinary white pigment against all 42 references,
  including ten ordered texture-color bins. An extra white curve hurt the
  reserved cards, so the source default remains. Blue and green candidates that
  failed texture gates are not included.
- Supply exact-printing original rules to all 292 M21 calibration inputs:
  287 MTGJSON records and five scan-reviewed empty bodies. A strict input helper
  rejects missing original rules or paragraphs that disagree with their source.
  Original type and flavor review remain separate from rules-source availability.
- Refresh the land comparison with original wording in both rebuild columns.
  Replaying all 33 lands preserves every earlier sampled frame/border pixel,
  so the stock-color evidence remains valid. Those renders were not text scores.
- Record input readiness separately from text-alignment approval in the set
  completion report, including stale-source checks. Preserve prior calibration
  receipts through explicit scope and native compatibility evidence.

References are reused development data. Chandra's Firemaw retains a visible
reference tint difference and is queued for printing-batch/reference review.
Paper, crowns, geometry, symbols, typography and whole-card certification remain
open. No set is claimed fully calibrated by this release.
