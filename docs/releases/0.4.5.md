# card-glint 0.4.5

This patch includes [PR #3](https://github.com/vishvananda/card-glint/pull/3)
and preserves physical frame selection when displaying original card wording.
Its optional controls preserve compatibility with existing consumers.

- Add `Instance.rainFog` and the matching PNG export option. Values range from
  0 (clear) to 2; omitted values and 1 retain the previous condensation density.
  Droplets, motion, refraction and other finishes retain their existing behavior.
- Preserve live pool ripple trails when all four emitters are occupied. Movement
  continues to drive slosh; emission resumes when a slot expires. Both ends of
  short strokes radiate, and spreading waves follow the flat surface metric.
- Correct the rain-fog test's preview port to match CI and report the actual
  software-GPU test platform. No physical-device performance claim is made.

- Add scan-reviewed original type lines for 316 Arabian Nights, Antiquities and
  The Dark printings, plus seven original rules bodies missing from the provider.
  These corrections are available through `resolvePrintingWording`; Oracle
  wording remains separate.
- Preserve basic and dual-land palettes when printed type lines omit subtypes.
  Keep enchantment frames for historical labels such as `Enchant Land` and
  `Enchant Artifact`, honoring semantic traits and explicit frame-color choices.
- Replay all 316 original-wording cards with frozen scan poses. Every pixel
  outside the type/rules/flavor regions stays unchanged. All historical frame
  and material selectors remain compatible, and all 292 M21 original inputs
  regenerate byte-for-byte identically with unchanged material/stock/mana values.

This establishes original-wording inputs for the next typography pass; it does
not certify text alignment. Flavor formatting, transcription outliers, unsupported
frame materials and 34 unresolved early-set scan poses remain tracked separately.
No set is claimed fully calibrated by this release.
