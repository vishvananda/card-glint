# card-glint 0.2.23

Restore early dual-land color ordering and Eighth Edition basic-land frames,
and add initial rendering coverage from pinned Magic Set Editor defaults.

- Correct five reversed dual-land band pairs across Alpha, Beta and Unlimited.
  The scan-bound audit covers all 29 printings. Revised's different striped
  text-box treatment remains queued.
- Select colored Eighth Edition basic-land plates from their land subtype and
  replace bare MTGJSON W/U/B/R/G text with the large printed mana symbol.
  Explicit frame-color overrides and custom rules remain authoritative.
- Add opt-in Future, Kamigawa flip and Battle templates, including shaped art
  masks, both flip panels and Battle defense. These are uncalibrated defaults;
  their typography, artwork crops, indicators and footer details need review.
- Record pinned MSE layout facts for ten standard template families. Source
  images remain external references and no MSE scripts are executed or bundled.
- Separate duplicated original flip text only when both records and the named
  reverse header agree. Preserve historical type words and normalize a/b
  collector suffixes when joining original physical-face records.

Existing ordinary calibrated layouts retain their geometry. The Revised
frame-enlargement comparison is an experiment, not part of this release.
New basic-land plates need their own color calibration. New template coverage
must not be presented as validated scan accuracy. Regenerate scores for changed
renderings; never relabel an earlier capture. The public showcase continues to
load only original repository assets.
