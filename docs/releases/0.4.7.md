# card-glint 0.4.7

This patch improves rules and flavor typography in Arabian Nights, Antiquities
and The Dark. Public interfaces remain compatible.

- Use shared size classes, margins, centering and line spacing for these sets.
  Antiquities' regular lettering is slightly wider; inline mana symbols retain
  their existing size, roundness and advance.
- Allow wrapping after inline em dashes while preserving style runs and leading
  attribution dashes. Preserve reviewed discretionary breaks on Rukh Egg and
  Mishra's Factory, and the missing activation colon on Candelabra of Tawnos.
  Reviewed corrections affect original wording only.
- Respect explicit alignment and the host's choice of original or Oracle text
  as its centering reference. Fit longer Oracle wording independently.
- Advance the generated-face cache revision so existing consumers repaint cards
  with the new typography.
- Replay all 316 printings. All 282 measured candidates match the native painter
  exactly; every pixel outside body text is unchanged. Default-width layout
  remains identical on all 316 inputs. Oracle fitting passes all three alignment
  modes.

With identical corrected original wording and frozen scan alignment on both
sides, mean text-fit indices improve from 0.421 to 0.592 for Arabian Nights, 0.415 to
0.604 for Antiquities, and 0.393 to 0.514 for The Dark. These are regional
similarity indices, not percentages of correctness. Of 282 accepted references,
256 improve and 17 regress by more than 0.05. The 34 unresolved scan poses remain
unscored. Short-heading alignment, verse formatting, historical inline-symbol
style and remaining placement outliers stay in the review queue; no set is
declared completely calibrated.
