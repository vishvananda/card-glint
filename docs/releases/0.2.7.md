# card-glint 0.2.7

- **Rainlit window** keeps the scene approximately anchored behind the turning
  glass instead of sliding the whole image with tilt.
- **Liquid prism** keeps artwork painted on the basin floor. Water piles toward
  opposing walls, rebounds and settles using the existing damped motion state.
- Printed overlays stay sharp; matching overlay foil and art-only coverage are
  unchanged. Saved finish values `rain` and `pool` remain compatible.
- No new textures, readbacks, asset builds or per-card light maps. Animation uses
  cached artwork and the existing shared caustic pass.

Window stabilization approximates a centered camera from the supplied normal;
it is not a world-space scene or a fluid simulation. Pixel regressions check
stationary scene features, card-attached floor features, local slosh and cache
reuse. Browser checks use software graphics, not physical-device FPS results.
