# card-glint 0.7.6

This patch corrects Arabian Nights mana-symbol roles and placement. Existing
consumer APIs remain compatible.

- Give original inline generic symbols their own printing colors: blue-gray
  on artifact frames and a dark translucent disc on red frames. Preserve the
  separate casting-cost treatment.
- Keep the printing's calibrated cost position, disc dimensions and spacing
  when modern symbols are selected. Modern glyph and numeral shapes keep their
  own proportions. Caller adjustments remain relative to printing defaults.
- Expose the inline color and opacity values in the set calibration controls.
- Preserve historical calibration evidence and score compatibility for
  unaffected sets through an exact, scoped source receipt.

Native checks cover all 92 printings in Original wording and both Oracle symbol
modes. Changes stay in the intended regions and preserve card silhouettes.
Another 182 native controls from other frame families are byte-identical.
Preparation keeps its existing cache behavior and adds no per-frame image
decoding, font loading or pixel readback.

This is a regional correction, not full Arabian Nights or Antiquities scan
registration certification. Further Onslaught P/T and generic-disc calibration
remains open. No external card art is added to the public showcase.
