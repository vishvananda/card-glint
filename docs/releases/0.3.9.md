# card-glint 0.3.9

The Magic pack restores the printed em dash after “Choose one” on all five
Planar Chaos Charms: Dawn, Piracy, Midnight, Fury and Evolution. These reviewed
corrections are available through `resolvePrintingWording`, with their exact
printing provenance. Oracle wording remains unchanged.

The accompanying text study retains the current shared typography: alternate
fonts, width changes and content-based sizing rules did not reliably improve
the validation cards. Font-size and wrapping outliers remain in the review
queue. Correct wording is accepted from the scans even where the unchanged
layout gives a lower overlap score; the 0.3.8 full-set report stays frozen.

This patch has no public interface changes. It includes the cardstock relief
and cached print-dot optimizations already shipped in 0.3.7 and retained in
0.3.8. Rendering continues to reuse prepared fonts, images and materials.
