# card-glint 0.2.20

Render Prepared cards with native left-side creature text and a separate
right-side spell inset, replacing the ordinary-frame fallback that omitted
its spell. Supply `layout: 'prepare'` with creature/spell `faces` and full-card
art on the parent.

- Preserve independent creature/spell materials, two-color page gradients and
  pinlines, neutral hybrid spell headers and blended legendary crowns.
- Fit both text panels independently, with measured headers and exclusions for
  the statistics badge and authenticity stamp. Share art bounds with printing
  holes, edge sources and optical effects.
- Cache prepared frame composites within a 16 MiB budget; share existing font
  and decoded-asset loaders. Prepared uses the rarity-first collector footer.
- Keep original wording and reviewed formatting bound to exact scan hashes.
  MTGJSON lacks original panel text/type fields for these SOS printings, so all
  72 panels were visually verified before comparison.

The comparison covers 36 ordinary SOS printings. Twenty-nine pass independent
frame normalization, and all render without text overflow. Mean spell-text
edge F1 improves from .273 to .652; white inset headers improve from .044 to
.750. These are component diagnostics, not whole-card accuracy percentages.
Seven black-card fits remain unscored, and typography/color outliers remain
listed in the Magic pack's Prepared comparison notes. No per-card renderer
settings were installed. Colorless plates absent from the pinned source fail
explicitly rather than silently using another frame.

Strict checks, native/WASM Clippy, build, package integration, browser, original
showcase, Magic layouts, accuracy regressions and the extracted release archive
pass locally. Full CI gates publication. Nyx treatments, Rooms, Battles and
physical double-faced layouts remain separate work. The deployed review search
adapter is not extended by this library release; its special-frame gallery
remains separate.
