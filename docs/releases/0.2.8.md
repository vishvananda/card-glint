# card-glint 0.2.8

- Publish the optional Magic drawing pack at `card-glint/magic`, with frame
  selection, layout geometry, text composition, art cropping and etching recipes.
- Include the separate `card-glint/magic/fonts.css` stylesheet, pinned external
  asset references, contribution guide and pack-specific fan-content notice.
  No third-party artwork, frame or font binaries are bundled.
- Keep the core and original showcase independent of the Magic pack. Core
  rendering APIs, cache budgets and finish IDs are unchanged.
- The showcase opens with classic foils and isolates pointer-driven reflections
  to the hovered card. Its README has a looping GIF and downloadable MP4.
