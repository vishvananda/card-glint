# card-glint 0.6.10

Printing now uses the reviewed fine CMYK treatment: translucent ink, brighter
light gaps, stable plate offsets and ink variation. Global dot-pattern blur varies
across fixed random patches and is capped at 0.5 reference pixels. Letter outlines
are not blurred. The default rim inset is 0.035; `inset: 0` retains full-bleed
printing. An omitted print-dot profile remains disabled.

Plate source samples and coarse fields are reused across blur taps. Tiers where
dots have faded out borrow the original textures, avoiding a redundant preparation
pass and cache allocation. Visible printing remains cached and mip filtered. Under cache pressure or mixed
instance settings, the procedural path uses an analytic blur footprint rather
than repeating the nine-tap preparation filter at every finish sample. This
keeps the same plate pattern with an approximate filter; cached cards and host
printing preparation retain the reviewed filter. Base and overlay sources stay
independent.

Gloss reflections increase by 10%; cardstock relief decreases by 10% at the
same amount. Public APIs, finish IDs and composition order are unchanged. Magic
face calibration is unchanged, so this finish update does not require rescoring
printing layouts.
