# card-glint 0.5.0

Adds `finish: 'holofoil'`, a reflective diffraction finish distinct from Prismatic.
It uses the same optical response as local hologram patches and supports finish
coverage, printing, cardstock, wear and PNG export. Existing finish names and
numeric IDs are unchanged. `holofoilVersion` allows feature detection.

This is a minor release because the public `Finish` union gains a member.
Consumers with exhaustive switches or maps keyed by `Finish` should add
`holofoil`. Existing renderer calls retain their behavior.

The Magic pack adds `artworkFoilMask(face, url, { invert?, tier? })`, returning a
prepared alpha raster aligned with illustration cropping, placement, zoom and
the frame aperture. White enables coverage; black and transparent pixels leave
it uncoated. Inversion applies before source alpha, preserving transparent and
partially transparent pixels. Unpainted backing outside an explicit illustration
placement receives no coating. Use the result in a document layer's
`finishCoverage.add` or `.exclude` mask.

Fine print screens integrate four subpixel screen samples before caching,
reducing grid artifacts without averaging the source lettering or alpha.
Coarse screens retain their existing sampling. Source conversion, font work and
GPU texture preparation stay outside pointer-motion frames; artwork-only
composition skips font loading and mana-numeral preparation.

Includes PR #6 and the 0.4.20 Dark mana calibration. Historical calibration
receipts remain pinned to their measured sources, with explicit reconstruction
and native differential checks for the new preparation path. This release does
not replace hosted scan scores or claim additional calibration coverage.
