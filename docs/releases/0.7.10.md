# card-glint 0.7.10

Magic text uses explicit font anchors and a shared fractional-size grid.
Colorshifted and Futureshifted name/type positions no longer depend on an
operating system's interpretation of malformed font metrics. Eighth Edition
keeps its calibrated alphabetic anchors. The renderer selects registered font
weights instead of requesting synthetic bold or italic outlines.

A real MPlantin Bold face supplies Futureshifted generic mana numerals.
Starting loyalty is centered relative to the printed shield; seven measured
planeswalkers improve from 2.95 to 0.57 reference pixels of average error.

The font checks use verified source bytes on Windows, macOS and Linux.
Document and worker measurements share the same anchors, advances and wrapping.
Rasterization can still differ slightly between browsers and operating systems.

Cached rebuilt faces receive a new font revision. Plain scan faces keep their
existing identities. Historical calibration evidence remains available, but
changed typography and full-card scores require fresh renders. Unchanged
frame/color regions and original wording retain separately bounded reuse;
unknown source changes remain invalid.

Public rendering interfaces and finish behavior are unchanged.
