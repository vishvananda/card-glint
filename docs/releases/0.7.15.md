# card-glint 0.7.15

Recognizes 46 additional recent promo, Alchemy and supplemental set codes through
explicit, reviewed symbol aliases. They use the existing complete rarity SVGs,
including their outlines, white details and gradients. Symbol aliases do not
transfer frame, wording or calibration profiles. Custom symbols and hidden-symbol
controls retain precedence.

Adds a Scryfall monochrome outline fallback for The Zeta Set. Explicit Keyrune
selection does not use that fallback. Darkhold and Nauctis remain pending usable
sources rather than displaying another set's icon.

The source audit downloaded and decoded 230 SVGs across 87 recent set entries.
The offline differential preserves 10,248 existing symbol URL/ink combinations
and checks 1,104 alias combinations. The 870 native compatibility probes and
renderer, package, browser and showcase checks passed. Historical source guards
remain exact; no calibration values, finish shaders or public interfaces changed.

Run `npm run magic:symbols:audit` to repeat the cached source check and generate
a local review sheet. See [recent set symbols](../../games/magic/docs/recent-set-symbols.md)
for sources, coverage and remaining gaps.
