# card-glint 0.7.2

Fixes PR #11: selecting the named `8ed-eighth` calibration with an
Eighth Edition printing preset or style now works. Validation checks the chosen
frame family instead of applying the M21-only guard to every named profile.

The Eighth profile remains limited to ordinary Eighth-family frames. Modern,
retro, colorshifted and dedicated layouts still reject incompatible profiles.
M21 validation remains unchanged.

This patch does not change public interfaces, painter geometry, typography,
assets or generated calibration values. Existing successful renders keep their
calibration evidence. An exact source projection accounts for the validation
fix and its generated dependency manifest; unknown changes still invalidate
the audit. Newly accepted explicit profile choices do not inherit old scores.
