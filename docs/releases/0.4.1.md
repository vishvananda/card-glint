# card-glint 0.4.1

This patch fixes frame black levels, colorshifted headings and foil lighting.
Existing consumer inputs remain compatible; no migration is required.

- Calibrate outer stock separately from interior frame ink. Alpha and Beta keep
  distinct outer charcoal and interior black levels. The study covers 37 sets
  with active HSB profiles and 1,021 accepted scan poses. Twelve new interior
  fits pass reserved-card validation, reducing shadow-region RGB error from
  13.26 to 6.64 byte units. Unsupported material cohorts keep their prior values.
- Replace Legends white/black apertures with the reviewed Fourth Edition
  source treatment. Widen Planar Chaos colorshifted edges and balance bevel
  brightness separately from texture contrast across all five colors.
- Lighten colorshifted name/type strokes while preserving glyph advances and
  placement. Calibrated heading shadows use the measured edge black. Across
  29 reserved cards, name overlap improves 76.67 to 77.22 and type overlap
  improves 74.21 to 74.54 out of 100. These are regional, not whole-card scores.
- Eliminate fractional retro-border seams in Chromium and WebKit by extending
  the stock mask outside the plate, preserving its inner aperture. Linux WebKit
  exposed the remaining seam responsible for the repeated CI failures.
- Keep foil lighting continuous through the flat pose and remove undefined
  shader math in sparkle and hologram highlights. Etched/Opal set-symbol masks
  preserve ink detail and holes, including styled rarity overrides. An optional
  `setSymbolMask` selection supports custom symbol images without changing
  existing inputs. Mask preparation is cached, outside animation rendering.

Color calibration remains opt-in for flat inputs and enabled by the import and
preset helpers. Measurements describe displayed scan references, not physical
ink. Alpha, artwork and independently fitted pigment colors retain their existing
boundaries. Both showcase GIFs and videos use the updated foil shaders and only
original repository assets.

The release checks include strict native/WASM Clippy, rustfmt, package/browser/
showcase tests, Magic accuracy and printing API regressions, stock seams in both
browser engines, foil continuity, symbol-mask/material tests and optical-surface
regressions. JavaScript, WASM, browser archive and immutable CDN assets are
published together.
