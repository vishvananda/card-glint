# card-glint 0.7.13

Fixes preparation stalls on ANGLE's Metal backend. Its non-blocking shader
completion query can remain pending until the browser window loses focus.
Preparation first polls asynchronously. After one second on that backend only,
it checks the actual link status to finalize the program. Other backends retain
non-blocking polling. Native finalization can briefly block during a cold compile.

Asynchronous linking also explicitly submits its commands before polling, so
detached canvases do not depend on a future drawing frame to flush the queue.
There are no shader, layout, font, calibration or public API changes.

Regression coverage includes stale completion, cancellation, context loss, link
errors, detached submission, and 40 exact finish-pixel comparisons with no warm
compilation. Timing observations describe preparation wall time; they are not
isolated GPU completion benchmarks. Historical flat-face evidence keeps its
exact reviewed source ancestry, without approving future source edits.
