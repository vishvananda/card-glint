# card-glint 0.4.15

This patch integrates the host-rendering APIs from PR #4 and the print-sampling
fixes from PR #5. Existing consumer calls retain their defaults; the new options
are additive.

Hosts can supply a `RasterHost`, discover native Magic assets and fonts, reuse
panel geometry, suppress rules ink, and color or omit selected type/stat spans.
`canonicalTypeLine` keeps semantic frame selection independent of a printed or
localized label. `FinishResources` exposes shared mask preparation, alongside
surface shader exports. Standalone coverage caches include the game-pack ID,
preventing masks from leaking between packs with identical local keys.

Varied halftone dots and holes now include neighboring impressions that cross
cell boundaries. The optional `createDisplayRaster` helper filters native
canvases for CSS previews and follows CSS sizing and display-density changes.
`printSamplingVersion === 1` advertises this support. Native exports keep their
resolution. Preparation remains cached, with no per-frame decoding, font loading,
shader compilation, mask readback or new animation loop.

Integration preserves the 0.4.14 filled artist credits and historical calibration
evidence. The default-rendering comparison is rebased to 0.4.14 and checks 870
pixel, measurement and layout cases using synthetic assets and browser fonts.
This is compatibility evidence, not fresh scan calibration. Historical checks
compose the host, artist, mana, title and calibration proofs without replacing
measured scan hashes.

Package checks cover the public host exports and Node-safe imports. Browser
regressions cover pack isolation, dot/hole cell continuity, CSS resizing, density
changes and disposal. The touch test waits for delivery of native release/cancel
events before inspecting state, avoiding a CDP acknowledgement race under load.
Browser automation does not establish physical monitor or mobile-device behavior.
