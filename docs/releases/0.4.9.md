# card-glint 0.4.9

This patch improves red frames and printing colors in Antiquities and The Dark.
Public interfaces remain compatible.

- Select Fourth-era source assets and fit shared frame/art-window geometry for
  each set. Compare source families using identical opaque regions and separate
  geometry and texture checks.
- Calibrate frame and text-box colors separately, with bounded frame contrast
  adjustments. Preserve the illustration and independently measured stock color.
- Add 24 qualified scan poses for repeatable comparison. Reject the Atog and
  Ball Lightning scans that fail recovery checks; neither influences the fit.
- Advance the generated-face cache revision so consumers repaint the new frames.
- Replay all 316 early-expansion printings: only the 26 intended red faces change,
  every text layout stays identical, and the other 290 faces are pixel-identical.

On reserved names, frame-boundary correlation improves from -0.011 to 0.930 for
Antiquities and from 0.039 to 0.962 for The Dark. Frame color distance falls from
8.37 to 1.50 and from 6.27 to 2.88 respectively; paper distance falls from 11.22 to
1.10 and from 9.22 to 2.14. These are regional diagnostics, not full-card accuracy
percentages. Headings, mana, set symbols, lower details and stock/corner checks
remain separate work; no set is declared fully calibrated.
