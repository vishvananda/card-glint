# card-glint 0.7.7

Onslaught creatures now use filled, bold P/T lettering instead of thin trimmed
strokes. The 28 px size stays unchanged; the right anchor moves 0.25 px and the
ink becomes lighter. Generic casting-cost discs use a measured paper color for
each physical frame material. Inline symbols and colored mana glyphs keep their
existing appearance.

The fixed-position filled-ink score improves from 61.94 to 78.38/100 across all
174 creatures. The unchanged whole-card metric improves from 76.48 to 76.71/100
across all 350 ordinary nonfoil printings. The same Original inputs, scans and
scan-only poses are used before and after. Validation includes previously viewed
development examples; it is not an independent release holdout.

All 1,400 native mode pairs preserve alpha, rules wrapping and pixels outside
the corrected regions. Etching masks are identical. Another 574 native controls
preserve other sets, inherited old-frame defaults and explicitly selected frames.
The new header-paper colors do not transfer to other sets without review.

Optional calibration controls expose P/T font weight and generic cost-paper RGB
by frame material. Existing profiles and consumer APIs remain compatible. Warm
preparation and painting introduce no new pixel readbacks.

The calibration report preserves unaffected evidence and requires current
evidence for changed components. The foil-only Onslaught alternate and remaining
ARN/ATQ scan-template coverage are separate follow-up work.

See the [study and reproduction commands](../../games/magic/docs/mirage-onslaught-study.md#onslaught-cost-paper-and-pt-recheck).
