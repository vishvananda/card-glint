# card-glint 0.6.11

Adds `FinishTextures(gl)` under `card-glint/finish` for hosts that already own
resident WebGL2 face textures. Prepare print dots and the shared cardstock map
directly in that context, avoiding an extra context, CPU readback and re-upload.
Both 2D textures and texture-array layers are supported. Printing results are
caller-owned, mipmapped sRGB textures; cardstock is borrowed from the helper.

Preparation restores touched host GL state. The documentation covers ownership,
cache keys, encoding, array integration and context recovery. Existing rendering,
byte preparation APIs and finish defaults are unchanged. This additive API ships
as a patch within the existing 0.6 host integration API.

Validation covers package exports and TypeScript consumers, native pixel and mip
parity, array layers, alpha, resource ownership, GL state, failure cleanup and
context recovery. No Magic painter, profile or flat-face raster dependency changes;
existing calibration scores do not need regeneration for this release. The exact
export-only ancestry check preserves historical receipts and still rejects later
unreviewed edits.

M21 calibration remains in progress and is not included in this release.
