Animated optical treatments and direct CDN inclusion.

- **Raindrops on glass:** seeded arrivals, refractive lenses, highlights and sliding drops.
- **Heat shimmer:** rising, animated distortion across the printed card.
- **Pool water:** moving caustics, refraction, damped slosh from card movement and local pointer ripples.
- **Showcase motion:** gentle two-axis idle drift, perspective pointer tilt, smooth handoff and reduced-motion support.
- **jsDelivr:** immutable checked browser builds, with matching JavaScript/WASM and a single-file HTML example.

[Try the showcase](https://vishvananda.github.io/card-glint/) ·
[Try the CDN example](https://vishvananda.github.io/card-glint/cdn/)

```js
import {
  createRenderer,
  IDENTITY,
} from 'https://cdn.jsdelivr.net/gh/vishvananda/card-glint@cdn-v0.2.0/browser.js';
```

The `.tgz` is npm-installable; the browser ZIP works with a plain HTTP server.
Both include precompiled WASM and its matching JS wrapper. `SHA256SUMS` and
`release.json` provide hashes and source/toolchain metadata.

New optional inputs: `Frame.time` in seconds, and `Frame.hover` with an instance
ID and top-left card UVs. Existing static render calls remain valid. The three
new finishes preserve clipping, depth, finish exclusion masks and over-finish
overlays. Animation reuses existing face and mask textures.

These are procedural optical effects, not a fluid solver. Heat refracts inside
the silhouette; transient ripple/slosh history is not part of PNG export.
Fragment work increases; the automated checks establish correctness and cache
reuse, not hardware FPS. Please compare performance on your own devices.
