# card-glint 0.2.18

Render Adventure cards with native book plates, independent permanent/spell
materials and measured page typography.

- Preserve the book fold, page edges, two-color pinlines, hybrid labels and
  legendary crowns; keep art, printing holes and effect apertures consistent.
- Size short spells from measured line demand, improving Stomp and Petty Theft
  without per-card renderer exceptions.
- Use Beleren Bold Small Caps for artist and power/toughness text, and support
  the newer rarity-first collector footer with an explicit host override.
- Add opt-in ELD/WOE spell-paper HSB profiles, clipped to the curved page body.
  CLB keeps its darker material. Preparation and decoded sources remain cached.
- Normalize comparison scans against independent uncalibrated frame targets,
  keeping paper-tone changes from altering the alignment target.
- Reject ambiguous duplicated original text in comparison inputs. Scan-reviewed
  corrections repair two corrupted CLB reprints and Oakhame Ranger's old type.

The corrected comparison covers 111 ELD/WOE/CLB printings; 80 pass frame-only
registration and none overflow. Mean spell-text F1 improves from 0.315 to 0.649
in ELD, 0.370 to 0.545 in WOE and 0.321 to 0.626 in CLB. These are component
measurements, not whole-card accuracy percentages. Fourteen component
regressions and 31 rejected fits remain documented. Wrapping, header materials,
texture and further treatments still have outliers.

Strict checks, native/WASM Clippy, build, package integration, browser, original
showcase, Magic layouts, accuracy regressions and the extracted release archive
pass locally. Full CI gates publication. Prepared, Rooms, Battles and physical
double-faced variants remain separate work; this release does not extend the
deployed review browser's ordinary-card search adapter to those layouts.
