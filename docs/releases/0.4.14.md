# card-glint 0.4.14

This patch replaces hollow artist-credit lettering with thin filled light ink
and a separate lower-right shadow on ordinary Arabian Nights, Antiquities and
The Dark cards. Shared set defaults refine the placement and width. Partial
perimeter thinning preserves fine strokes, including the copyright glyph.
Public interfaces are unchanged.

The ink palette is retained from the existing renderer; this is a shape and
shadow correction, not a new calibration of printed ink color. Preparation
uses one temporary canvas during cached face composition. Animation adds no
font loading, asset decoding or pixel readback. Alpha/Beta/Unlimited/Revised and
other sets retain their previous typography.

The fit uses 99 calibration printings with original credits and frozen frame
normalization. The known shifted Gaea's Touch variant is excluded from fitting
but retained in reports. Three fixed crops combine local contrast, filled-area
agreement and edge overlap, with a stroke-width penalty. Each material and
artist receives equal weight. Review compares both images at the same canonical
resolution, rather than enlarging a scan beside a sharper native rebuild.

Repeated reserved artist-region contrast similarity changes as follows:

| Set            | Printings | Before | After |
| -------------- | --------: | -----: | ----: |
| Arabian Nights |        51 |  64.0% | 70.2% |
| Antiquities    |        71 |  63.2% | 70.3% |
| The Dark       |        84 |  72.2% | 76.0% |

These are regional similarity diagnostics, not correctness percentages. The
same reserved scans were inspected during earlier model review, so these are
repeated validation results, not a fresh holdout. Filled-area and edge measures
also improve in aggregate. Stroke-width error improves for ARN/ATQ; The Dark's
error rises from 0.1354 to 0.1519 and remains an explicit review item. Individual
regressions and limitations remain in the calibration evidence.

All 316 cards were replayed through the native painter. All 306 scored candidate
footers reproduce exactly. Changes on 309 cards stay within the artist-credit
region. The seven unresolved Dark land/gold cards retain their previous pixels;
ten unresolved poses remain outside scan scoring. Eighty-four unrelated cards
across twelve sets retain identical native PNGs. Historical calibration receipts
keep their measured hashes behind the bounded artist-only compatibility proof.

The existing whole-card structural index stays at 74.13 because its eligibility
policy excludes unverified credits. A separate local aggregation that admits
these scan-reviewed credits moves from 74.18 to 74.23 across 306 cards; 201
improve. These two indices use different eligibility and must not be mixed.
Neither report updates the hosted accuracy graphs.

The set ledger remains partial: power/toughness, ink-color nuances, unresolved
frames and remaining typography work are separate obligations. Hosted accuracy
eligibility and saved review data are unchanged.
