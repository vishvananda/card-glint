# card-glint 0.6.12

Publishes the M21 calibration batch and makes its shared style the fallback for
compatible modern frames without an independent printing calibration.

M21 now has reviewed ordinary frame/paper sources, colored-artifact panels,
land treatments, paired-color legendary crowns, stock and interior black levels,
mana discs/glyphs/numerals/shadows, contextual heading forms and fractional type
fitting. Collector rows, artist/legal text, power/toughness and large basic-land
symbols are included. Planeswalkers receive coordinated foreground/paper colors,
type and ability geometry, loyalty badges/numerals, colons and static-ability
wrapping. Exact-printing traits such as Fabled Passage's gold palette stay local
to M21; inherited styles keep their own printing content.

The full native census retains all 297 ordinary Original printings, including
292 nonfoil and five foil-only references. Comparison-only affine normalization
covers translation, scale, rotation and shear. It never changes the renderer per
scan. The current frozen whole-card structure index is 80.525/100 (80.702/100 on
nonfoil cards), with regional coverage and residuals preserved in the evidence.
These are similarity indices, not correctness percentages or a color metric. The exact
0.6.11 replay scores 73.085/100 on the same recipes and normalized references;
278 printings improve and 19 regress. Common eligible-region scoring gives
73.086→80.525/100, retaining identical paired coverage.

The shared typography wins the tested global alternatives. Diagnostic individual
size fits and alternative font/orphan policies are not shipped: visual review and
separate rules/flavor checks expose wrapping tradeoffs that a combined score can
hide. Known rules/flavor outliers and incomplete component-certification checks
remain visible; this release does not mark the entire M21 completion ledger green.

Adds opt-in Oracle flavor text:

```ts
withCardWording(face, wordings, 'oracle', { includeFlavorText: true });
```

The Scryfall and MTGJSON providers forward the option. The existing Oracle
default still omits flavor text, and Original wording remains independent.
This is an additive patch within the 0.6 API.

The release comparison shows every ordinary M21 printing as original scan,
0.6.11 rebuild and 0.6.12 rebuild. External illustrations remain client-fetched;
the review server hosts art-free plates, masks and metadata only.

Validation includes strict Rust/TypeScript/ownership checks, package/browser/
showcase tests, Magic and worker/host regressions, exact historical-source
reconstruction, native scope/alpha/etching audits and full-population score
controls. Renderer effects and their defaults are unchanged from 0.6.11.
