# card-glint 0.3.7

The Magic pack now calibrates Future Sight's futureshifted frames. Regular,
land/colorless and full-art sources have separate shared geometry, mana and
expansion-symbol placements. Titles, type lines, rules placement, illustrator
credits, copyright/collector numbers and power/toughness use measured defaults.
Incomplete art crops keep their scale and use a solid fill for missing strips.

Color corrections are bound to the exact source plates. Ordinary five-color
frames have independent paper and panel masks. Sparse artifact, land, colorless
and textless materials have separate evidence; failed transfers retain source
values. Ghostfire's correction has only within-printing evidence. All derived
materials are cached during preparation, with no recoloring during animation.

All 81 futureshifted printings render. Across the 80 accepted frame-only scan
poses, structural match improves from **53.0% to 72.6%**; all 80 improve.
Mass of Ghouls remains excluded for its weak bottom edge. The 99 ordinary FUT
printings are outside this study. The index measures fixed-region structure,
excluding color, incomplete artwork and unverified legal-text diagnostics.
It is not a percentage of correct pixels. Rules-size/weight differences, land
paper blends and source texture differences remain in the review queue.

`resolvePrintingWording` is now available from `card-glint/magic`. This pure
helper applies reviewed corrections for an exact printing ID to supplied
original/Oracle wording and returns provenance. Hosts continue to own fetching
and persistence. Reviewed Future Grandeur labels preserve their italic label,
dash and existing flavor; Oracle wording remains independent.

Optional `Instance.wear` adds persistent edge abrasion and shuffle scratches to
all finishes, including gloss. Its amount and seed are also accepted by PNG
export. The showcase exposes the wear presets using only original repository
assets. No additional textures, readbacks or animation passes are required.

These interfaces are additive, so existing consumers remain compatible.
Planar Chaos is next, starting with its color-shifted frames.

This release also includes optional cardstock coating relief for optical finishes and
experimental process-ink dots. The relief map is shared and mip-filtered;
zero or omitted controls keep the coating smooth. Gloss independently uses a
10% softer reflection, with or without relief. Matching print-dot settings
reuse a bounded 16 MiB GPU cache instead of reevaluating screens on every frame.
Both controls support PNG export and context restoration. Magic editors can omit selected text runs in
bounded regions and optionally lift the outer black-border ink level. These
options leave the default calibration and artwork unchanged.
