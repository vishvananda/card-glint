# card-glint 0.7.8

Modern mana symbols now keep the selected historical frame's calibrated cost
position, disc size and spacing. This extends the earlier Arabian Nights fix
to every retro set. Modern glyph shapes, numerals and colors remain independent
of the historical symbol treatment. Caller adjustments still apply afterward.

The audit covers 278 ordinary sets and 16,885 frame configurations. It found and
removed geometry differences in 737 configurations across 30 sets. A native
replay of 216 material/set controls produced 648 comparisons: original-symbol
renders were unchanged; modern-symbol changes were confined to the mana-cost
region. These controls establish rendering scope, not every-card scan accuracy.

The modern-retro face cache key is revised so cached faces receive the fix.
Original-face and etching keys remain unchanged. Exact source ancestry preserves
existing Original calibration evidence; the corrected modern renderings are
not treated as equivalent to their previous versions.

The calibration report also distinguishes six historical M21 color proposals
that were not adopted from failures of the selected calibration. Their review
history remains available. Source mismatches and outstanding component audits
remain visible.

No public API changes.
