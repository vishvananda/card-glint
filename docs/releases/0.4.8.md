# card-glint 0.4.8

This patch improves short rules and flavor text in The Dark. Public interfaces
remain compatible.

- Use a narrower centered block for short original text, including mixed rules
  and flavor. Position shorter blocks with a shared line-count rule. Longer
  bodies retain the existing regular and compact typography.
- Correct reviewed original wording on Drowned, Miracle Worker, Marsh Gas,
  Grave Robbers and Brothers of Fire. Preserve activation punctuation, inline
  attributions and the roman book title within Miracle Worker's italic flavor.
  Oracle wording remains separate.
- Respect explicit alignment and the host's original/Oracle centering reference.
  Advance the generated-face cache revision so consumers repaint the new text.
- Replay all 316 early-expansion printings and test all three Oracle alignment
  modes. Every pixel outside body text stays unchanged; Arabian Nights and
  Antiquities remain pixel-identical. All 97 scored Dark candidates match the
  native painter exactly.

With corrected original text and fixed scan alignment on both sides, The Dark's
mean regional text-fit index improves from 0.520 to 0.577: 17 cards improve and
80 stay unchanged. These are similarity indices, not percentages of correctness.
The 34 unresolved early-expansion scan poses remain unscored. Font weight,
historical activation-symbol style and remaining wrapping/source outliers still
need review; no set is declared fully calibrated.
