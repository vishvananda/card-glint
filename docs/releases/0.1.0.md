First prebuilt release of card-glint, a game-neutral card renderer with a
Rust/WASM core and a WebGL2 browser backend.

- Cached etching, Opal embossing, cold foil, prismatic foil and regular finishes.
- Explicit composition layers, foil exclusion masks, instanced scenes and picking.
- Original fantasy showcase with three generated illustrations; prompts and provenance included.

[Try the interactive showcase](https://vishvananda.github.io/card-glint/).

Choose **card-glint-0.1.0.tgz** for an npm/Vite/TypeScript application:

```sh
npm install https://github.com/vishvananda/card-glint/releases/download/v0.1.0/card-glint-0.1.0.tgz
```

Choose **card-glint-0.1.0-browser.zip** for a plain HTML page. Extract it, serve
the directory over HTTP, and open `index.html`. The example includes local artwork
and needs no bundler. Both archives include precompiled WASM and its matching
JavaScript host; consumers do not need Rust. The npm archive also includes types.

`SHA256SUMS` verifies both archives and `release.json`; the latter records the
source commit and build toolchain. CI tests an independent npm consumer and
renders a card from the extracted browser archive before publication.

WebGL2 is required. Static faces and fonts are rasterized by Canvas2D; WASM owns
cache policy, scene planning, picking and pixel kernels. The API is an early
0.1 release. External game assets are not bundled.
