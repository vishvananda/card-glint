# card-glint 0.7.4

This patch packages measured early-frame improvements. The through-Fourth
Edition audit remains in progress; the calibration ledger keeps its remaining
component and source reviews visible.

- Improve Arabian Nights and Antiquities profiles with scan-bound typography,
  mana and frame measurements.
- Improve Revised frame geometry, filled name/type lettering, original rules
  layout, illustrator credits, power/toughness and historical mana colors and
  placement.
- Improve Fourth Edition text size classes, reviewed centering, fractional
  flavor metrics and land text. Basic-land mana symbols now sit higher while
  their calibrated words and wrapping remain unchanged.
- Use Fourth Edition as Ice Age's provisional baseline, preserving black
  surrounds, Ice Age symbols, historical mana and printing-specific wording.
  Mirage and Onslaught remain the next independent default-family studies.
- Correct reviewed original wording and artist credits, including Revised
  printing text, forty Legends artist credits, Fourth Gloom paragraphs and
  unprinted Wall reminder rules in Unlimited and Fourth.
- Report source readiness separately from layout approval. Fourth now has
  reviewed type inputs for all 378 printings and complete scan-read body
  reviews for 33. Unreviewed bodies retain explicit partial status.

The optional rules typography control `symbolOffsetY` moves whole inline mana
symbols by a fraction of their diameter. Positive values move down; the default
is zero. It does not change the text baseline or wrapping. Existing callers
remain compatible, so this is a patch release.

Fourth's current 378-card whole-card mean is 80.37/100. The last basic-symbol
change improves all fifteen basics, with 1,948 other native variants and their
layouts unchanged. These scans are reused development data, not a holdout.
Matching scores are retained only when native pixels, wording, scan identity,
normalization and metric inputs agree.

Validation includes strict Rust checks, package/browser/showcase checks, the full
Magic accuracy suite, independent native prototypes and original/Oracle/etching
isolation checks. No external card artwork is added to the public showcase.
