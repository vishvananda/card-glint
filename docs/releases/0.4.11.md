# card-glint 0.4.11

This patch improves ordinary Arabian Nights, Antiquities and The Dark titles.
It changes no public interfaces.

- Move titles into the measured name area, with shared size, width and position
  per set. Existing mana clearance still limits long names.
- Preserve open light/dark title lettering for Arabian Nights and Antiquities.
  The Dark retains solid light lettering. A comparison of alternate source fonts
  favored the existing font, so no font download is added.
- Leave The Dark's unresolved land and gold frames on their previous treatment.
  Custom frame choices and unrelated sets retain their existing rendering.
- Record title evidence separately from type-line calibration in the set ledger.
  Historical measurements retain their original identities through bounded,
  hash-checked source reconstruction.

The native replay covers all 316 printings: 309 titles change and seven unresolved
frame cases remain unchanged. All 306 small title previews reproduce the native
full-card pixels exactly. No pixels outside the title area change. A separate
84-card replay across twelve other sets is byte-identical.

Repeated validation uses 206 printing scans excluded from parameter fitting;
these scans were inspected during earlier studies and are not a fresh holdout.
The title-region two-polarity edge overlap improves as follows:

| Set            | Before | After | Improved validation printings |
| -------------- | -----: | ----: | ----------------------------: |
| Arabian Nights |  52.7% | 69.8% |                       51 / 51 |
| Antiquities    |  49.6% | 64.0% |                       71 / 71 |
| The Dark       |  51.0% | 73.4% |                       84 / 84 |

Both original comparison crops pass. An additional crop bounded by baseline
lettering also passes, with 205 of 206 improving and one 0.10 percentage-point
regression. These are title overlap measurements, not whole-card correctness
percentages. Ten unresolved scan normalizations remain excluded from scoring.

Using the unchanged application metric, the local whole-card structural index
improves from 70.15 to 71.68 for ARN, 69.11 to 70.47 for ATQ, and 70.02 to 72.01
for DRK (out of 100). Of 306 qualified printings, 303 improve; three ATQ scans
regress by at most 0.10 points. Non-title component diagnostics remain identical.
This local report retains the existing legal-credit exclusion and does not update
hosted score charts or certify complete-set accuracy.
