# card-glint 0.5.3

Opting into print dots with an empty profile now uses amount 0.35, period 2
source pixels and variation 0.5. The settings come from an Alpha frame-texture
comparison at 732px card width. An absent profile still disables added dots;
this is a visual approximation, not a press simulation.

Use `printDots: { artwork: false }` for scanned illustrations. The frame keeps
its dots, while the recipe's artwork windows are excluded. Generated art can
use `{}` to include it. The option works in cached preparation, mixed-instance
rendering and PNG exports. Host rendering exposes the same optional windows
through `FinishResources.printDots`; `DEFAULT_PRINT_DOTS` is public.

Alpha receives the reviewed shared rules/flavor layout adjustments for ordinary
and centered passages, preserving filled ink. Dense, mixed-alignment and
out-of-bounds cases keep their existing layout. This is a typography improvement,
not whole-set calibration approval. Downloaded experimental Alpha frame assets
and reconstruction overrides are not included in this release.

All API additions are optional and existing explicit print settings remain valid.
