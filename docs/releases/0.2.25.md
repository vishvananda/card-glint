# card-glint 0.2.25

The printing-reference adapter now distinguishes scan-verified empty rules from
missing source data for 73 printings in Alpha, Beta, Revised, Eighth Edition and
M21. Original mode retains their flavor text and actual printed types. Oracle
mode keeps modern abilities and types.

- Remove the incorrectly inherited Defender text from Alpha and Beta Wall of Ice.
- Restore obsolete printed types, including Summon Lions, Creature — Eel,
  Creature — Monster and Artifact Creature without later subtype additions.
- Keep inline poetry attributions inline where the scan shows them. Preserve the
  upright book title within Giant Octopus's italic flavor attribution.
- Bind each correction to its printing UUID, name and scan hash. Missing
  MTGJSON text elsewhere remains unverified; it is not assumed to be empty.
- Prevent caller-supplied replacement body text from inheriting a historical
  scan review that covered different wording.

All 73 corrected inputs passed the existing frame alignment and score coverage
requirements with their frozen scan transforms unchanged. This expands verified
score coverage; it is not a claim of improved typography on every card. Rebuild
scores using the corrected original wording before comparing layout changes.

The renderer's frame geometry, textures and Oracle defaults are unchanged.
