# card-glint 0.3.11

Planar Chaos short passages now avoid short rules endings and single-word flavor
orphans when a small size reduction removes the extra line. The shared policy
improves Dawn Charm, Ghost Tactician, Saltblast, Piracy Charm and Serendib Sorcerer.
It retains multiword flavor endings and introduces no printing-ID layout values.
All 160 other original printings remain pixel-identical to 0.3.10.

Across 156 accepted, independently normalized scans, structural similarity rises
from **80.89 to 81.57 / 100** under the live scoring method. All five changed cards
improve; 151 are unchanged. Six scan-alignment exclusions and three split layouts
remain outside this score. The live method excludes unverified source fields,
so these numbers are not directly comparable to earlier offline reports.

The initial broader rule regressed Serra Sphinx and was rejected. The adopted
flavor guard was evaluated after reviewing that failure; this is repeated
validation, not an untouched holdout. Dense-text outliers, including Retether
and Heroes Remembered, remain open.

All 324 single-face original and Oracle layouts retain every word and fit their
measured bounds. Roiling Horror's longer Oracle wording now renders at 14.25px,
using a bounded fallback below the normal 15px minimum while retaining P/T
clearance. Original wording remains unchanged.

This patch changes no public interfaces or animated rendering work. Native
raster replay, original/Oracle layout checks, package/browser/showcase checks,
strict Clippy and formatting validate the change. The Magic accuracy fixture
records all before/after hashes, score coverage and measurement limits.
