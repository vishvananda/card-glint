# card-glint 0.4.0

This minor release adds public printing controls and provider converters. Existing
renderer and Magic-card inputs remain supported; no consumer migration is required.
The new printing-style and preset contracts have their own version-1 identifiers
for persisted editor selections.

- Choose complete printing presets, share set styles with ordered frame rules,
  and compose per-card/per-face overrides without rewriting source card data.
- Hide or move artist, legal, collector, mana and set-symbol groups on supported
  ordinary and Futureshifted frames. Customize numbering, symbols and frame colors.
- Share artwork crop, focal point and zoom between previews, color painting and
  etching. Futureshifted frames also support art behind translucent rules paper.
  Unsupported layout/control combinations report explicit compatibility failures.
- Convert Scryfall and MTGJSON records through pure `fromScryfallCard` and
  `fromMtgjsonCard` helpers. Preserve independent panel colors, original wording,
  historical mana order, land palettes and face/art pairing. Joined original
  panel text requires an unambiguous source boundary. Hosts still own fetching,
  storage, reviewed corrections and finish selection.
- Expose `resolvePrintingArtist` for eleven reviewed physical credits, including
  five Planar Chaos cards credited to Dan Scott. Canonical provider metadata
  remains separate. Artist-region overlap for those five improves from 69.13 to
  88.74 out of 100; this does not change whole-card scoring eligibility.

The renderer core remains game-neutral. The existing showcase uses only original
repository assets; the separate Magic preset example loads the pack's attributed
external assets. Color calibration remains opt-in for existing flat inputs and is
enabled by the new import/preset helpers. All comparisons use unshaded printing;
optical finishes are not part of the accuracy score.

Validation covered 1,667 cached provider cards, the five early planeswalkers and
the original wording on all six Planar Chaos split panels. The API integration
preserves the exact unshaded raster for 1,370 existing Alpha, Beta, Unlimited,
Revised and Planar Chaos inputs, compared with the candidate that already includes
the printed-artist corrections above. Package, browser, showcase, preset-demo and
printing API checks pass, along with strict native/WASM Clippy and formatting.
