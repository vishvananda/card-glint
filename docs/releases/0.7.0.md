# card-glint 0.7.0

Adds the named `8ed-eighth` calibration baseline for ordinary Eighth-style
frames. Compatible cards inherit missing geometry, typography, mana, materials,
credits and basic-land glyph settings. Exact set and component fits take
precedence. White and black surrounds keep separate colors. Printing content,
set symbols and independently reviewed overrides stay with the recipient.
Planar Chaos and dedicated special layouts retain their own policies.

The complete ordinary English nonfoil Eighth audit covers 357 printings.
On identical frozen affine scan poses and the same metric, the structure index
improves from 70.19 to 81.36/100 after Original wording corrections. Titles,
type lines, mana, frame geometry and credits show the largest gains.
All 357 scans normalize successfully; 144 known native warp controls pass.
These indices measure similarity, not a percentage of correctness or a color
measurement.

Fixes reviewed printed types and artist names, City of Brass's source plate,
starter collector denominators, cost-symbol geometry/paper colors, thin inner
frame rules, headings, footer placement, rules centering and dense-text fitting.
Two-color lands use a separate shared paper/header calibration rather than the
basic-land palette. Large basic-land glyphs have measured position/contour fits
and canonical shadow units.

A single literal Eighth profile holds the shared settings. The lazy entry loads
its donor only when needed, honors exact-only policies, and respects inherited
set codes. Frame-derived outlines and recolored images use the bounded material
cache; animated frames add no decoding, font work or readback.

The public calibration report can now identify `8ed-eighth` as an inherited
default. This widens its TypeScript profile union, so this release increments
the minor version. Existing entry points and synchronous rendering remain
available.

The audit records known text wrapping, source-bevel/texture and large white
land-symbol residuals. Foil-only records remain inventoried and excluded from
ordinary pigment fitting. Receiving sets are not marked calibrated merely
because they inherit this baseline. See the
[Eighth audit](../../games/magic/docs/eighth-edition.md).

The unaffected-frame proof covers 266 cases and 1,596 exact native pairs, including
unchanged M21 and Planar Chaos controls. Score reuse requires identical pixels,
reference, pose, card semantics and metric/decoder identities; unknown code
changes invalidate it.
