# card-glint 0.2.13

Correct several Magic frame apertures and historical printed components while
retaining the existing source assets and shared calibration profiles.

- Center M15-style planeswalker art in the frame and clip it to the curved
  opening for both ability-box heights, including separated artwork layers.
- Extend Fourth-family artwork beneath its keyline, removing the uncovered
  strip on Revised cards. Correct the white-paper mask at the keyline and
  remove the false inner gray bevel from the Seventh-family white texture.
- Move old-frame mana discs using 26 validated set/stock profiles covering
  661 nonfoil examples. The Urza sets now use the measured shadowless-disc
  position. The List retains its previous placement after a reserved regression.
- Correct Urza artist and copyright placement and reserve space for creature
  stats on long credits. Keep the existing power/toughness size after rejecting
  a larger candidate. Artist and legal edge-overlap scores improve from .425 to
  .684 and .204 to .663 across 49 reserved examples.
- Restore the Seventh Edition uncommon/rare symbol's white outer rim with a
  checksum-guarded SVG patch. Preserve the interior gradient and shadow.
- Select the existing Eighth Edition plate for ordinary `frame: 2003` reference
  inputs. Hosts should preserve that family when switching wording modes.
- Exclude foil-only printings from new color samples and adoption. Remove five
  active mana-color targets sourced from foil-only references; no active frame
  profile required removal.

The symbol follow-up accounts for all 445 set/frame/stock groups in the major-set
plan, using cached per-scan frame normalization. No proposed further move passes
all production-raster validation gates, so existing placements remain unchanged.
The report explicitly retains missing-source, sparse-normalization and regression
cases for review; completing the audit does not certify every symbol as accurate.

Build, strict lint/format checks, package integration, renderer/browser, original
showcase and Magic regression checks pass. Scores above measure component edge
overlap, not whole-card accuracy. Rectangular art crops cannot reconstruct
artwork printed over a planeswalker's frame. The review app and external reference
images remain separate from the library.
