# card-glint 0.6.8

Unlimited dual lands now crop the printed plate upward while keeping the lower
edge fixed. Their illustration windows follow the corrected apertures. A narrow
source-local adjustment restores the darker lower bezel without changing the
paper, rules text or upper frame. The existing assets and material API are retained.

The installed profile was replayed across all 302 Originals and 604 Oracle faces.
Only the ten duals change: the other 292 printings remain pixel-identical in all
three modes. Every body layout and etching raster is unchanged, with no missing
assets or overflow. The complete-set structural index rises from 70.76 to
70.97/100; the ten duals rise from 64.01 to 70.44/100, with no regressions.
These indices exclude credits/legal and the outer edge. Separate fixed-pose edge
diagnostics and full-card/corner review validate the crop and lower bezel.

The update changes one set profile and is API compatible. Editor proposals made
against Unlimited profile revision 1 must be rebased onto revision 2. Numerical
receipts retain the prior release and every reference/pose identity. External art,
scans and fonts remain outside the repository and public showcase.
