# card-glint 0.7.12

Software rendering now avoids compiling a printing shader when a face and its
overlay already filter the dots out. Cached visible printing uses plain texture
sampling. Analytic fallbacks compile only for mixed settings or cache pressure;
entries stay protected until those fallbacks are ready. Native finish programs also exclude code for other finishes before compilation.
The full CMYK preparation pass keeps its color plates and area samples in
uniform loops to avoid duplicating the filter in Windows shader compilers.

Low quality reduces rain/heat blur taps, neighboring stationary rain beads, pool
irradiance taps, and fine etched/opal sparkle. Lighting, animation, masks and
printing remain active. The default quality and public API are unchanged.

Full-quality pixel checks match the historical renderer across all ten finishes,
including printing and local holograms. Regression tests cover filtered printing,
cached sampling, mixed-instance fallback and zero warm shader compilations.
Magic frame geometry, text and calibration values are unchanged.

See the [Windows software test report](../testing/windows-software-0.7.12.md)
for high/low results, 300-face stress checks and measurement limits.
