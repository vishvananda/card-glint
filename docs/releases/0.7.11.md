# card-glint 0.7.11

Hosts can opt into cheaper finish preparation on software graphics drivers with
`createRenderer({ canvas, finishQuality: 'auto' })`. The renderer reports its
resolved `finishQuality`; `finishQualityVersion === 1` detects support. Explicit
`full` and `reduced` choices are also available. The default remains `full`.

Reduced mode bounds cached print filtering to 488 pixels wide, uses the analytic
CMYK coverage path, and prepares a smaller cardstock relief map. Finishes,
printing coverage, artwork exclusion and pose-driven lighting remain active.
Preparation stays cached during motion. Hardware and unknown drivers retain
full quality under automatic selection.

The regular, gloss and prismatic full-quality controls match 0.7.10 pixels with
printing and cardstock enabled. Linux, macOS and Windows font checks pass.
Magic frames, typography, wording and calibration values are unchanged.

This is an additive, compatible API update. Hosts must request automatic or
reduced quality to use the software graphics optimization. See
[host integration](../host-integration.md#software-rendering-profiles).
