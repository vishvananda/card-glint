# card-glint 0.2.15

Improve artist credits and power/toughness on Eighth Edition frame layouts.

- Restore the printed artist brush and correct credit size and placement.
- Use Matrix Bold Small Caps for lining power/toughness numerals. Variable
  stats use five-point stars instead of the font's legacy dot character.
- Load the added font and brushes through existing face-preparation caches.
- Verify scan alignment against each exact source plate and border mask;
  retain rejected fits instead of using uncertain offsets for calibration.
- Cache reference edges for CPU placement searches and validate lettering
  separately from frame texture.

The study covers six sets and accepts 51 of 80 frame fits. On reserved names,
artist edge overlap improves from .640 to .842 and power/toughness from .596
to .771. Two later-set 1/1 examples retain small glyph-only regression flags;
mismatched printed artist names are excluded. These are sampled component
measurements, not a claim of whole-library accuracy. Set-symbol placement
candidates remain separate from the released footer changes.

Strict checks, build, package integration, browser, original showcase, Magic
layouts and accuracy regression suites pass.
