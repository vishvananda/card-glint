# card-glint 0.6.1

Alpha names can now be adjusted through the calibration API while retaining the
existing frame and body painter. ABU dual lands select their full-frame outline
color independently of their concentric text-box stripes.

- `describeSetCalibration('lea')` reports `adapter: 'title'` and bounded controls
  for name offsets, size, width, filled gray and shadow. Other groups remain
  unavailable until their profile adapters are migrated.
- Empty name proposals preserve the native printing pixels. Save an evaluated
  name proposal with `exportSetTitleCalibration` for a single-file contribution.
- Correct Badlands, Plateau, Scrubland, Taiga and Tundra outline selection without
  changing their interior paper ordering. Canonical land subtypes remain usable
  when the displayed original type is only “Land”.
- Alpha name alignment and ABU dual-outline review are explicitly reopened in
  the calibration ledger. Historical evidence and scores retain their identities.

This is a compatible patch. Existing full-profile candidate and export APIs
remain unchanged. Experimental reconstructed frames remain outside this release.
