# card-glint 0.3.0

This release integrates the `foils` branch, adds a local reflective coating for
Magic security stamps, and restores equal-width colored rules-box borders on
Alpha, Beta, Unlimited and Revised dual lands.

## Consumer migration

The public `Finish` union adds `'gloss'`. Existing finish names and their call
signatures remain supported, but exhaustive TypeScript switches and
`Record<Finish, ...>` mappings need a gloss case. This is a minor release for
that source compatibility change. An omitted finish still means `'regular'`.

`FaceRecipe.hologram` is optional and independent of the instance's finish.
It supplies a cached alpha mask, normalized rectangle, strength and stable seed.
Existing recipes need no changes. The Magic pack supplies the local oval coating
where supported; hosts can select `finish: 'gloss'` for a glossy card surface.
Comparisons and accuracy measurements continue to use unshaded printing.

## Rendering changes

- Add clearcoat gloss and update prismatic, cold-foil, opal and animated-surface
  shading from the foil branch. Fix second-art-window clipping and ImageBitmap
  upload orientation.
- Reuse the updated spectral palette for local hologram diffraction. The printed
  oval, emblems and border stay visible; view and tilt move its reflection.
  Local masks are cached, and both shader variants compile during context setup.
  Animation does not decode assets, read masks or compile shaders.
- Draw three equal colored bands between thin dark outer and inner edges on
  early dual lands. Use one physical thickness on every side, with separate
  ABU and Revised source geometry. Remove the former ABU outline before drawing
  its replacement so it cannot appear beside the new border.

Compared with 0.2.28 on ten Revised duals, whole-card structural match changes
from 73.92% to 74.22%. For the accepted frozen ABU references, Alpha changes from 55.24% to
57.88% (nine cards), and Beta from 57.07% to 59.37% (eight cards). These are
calibration results on the fitted cards, not independent validation or a
percentage of correct pixels. Individual regressions remain recorded. Twelve
ABU duals without accepted normalization remain visual review only; all fifteen
ABU and fifteen Revised basic-land controls remain pixel-identical.

The hologram is a procedural approximation. Older sheet-position variation and
M21 mana shadow, spacing and numeral calibration remain follow-up work. Browser
pixel tests use a deterministic software GPU; they do not establish physical
Safari/Metal performance. Public showcase assets remain original repository art.
