# card-glint 0.7.9

Native finish programs compile only when requested. Preparation polls parallel
shader completion before inspecting link status. Non-liquid finishes omit the
liquid shader source. Readiness and PNG export wait for the selected finish,
including scene changes during preparation. Revision replacement, context loss
and disposal cancel pending waits. Already-aborted callers start no work.

FinishResources.documentMaskData transfers coverage through a pixel-pack buffer
and GPU fence. It yields while the transfer is pending, retains its source leases
until completion, and returns the same bottom-up R8 bytes.

FinishTextures adds asynchronous ready(signal?) and a borrowed caustics(time)
map for host materials. Existing synchronous preparation remains supported.
Host state is restored after preparation and caustics updates.

For a deterministic first draw of a new finish, call updateScene before awaiting
ready. Interactive render loops can instead honor invalidate while compilation
is pending. Pose-only animation requires no additional preparation.

Forty finish/coating/printing combinations match the previous shader pixel for
pixel in deterministic software WebGL. Lifecycle checks cover scene changes,
cancellation, resource ownership and readback recovery. These checks do not
establish Windows driver timings.

CI builds once and distributes its unique checks over four parallel jobs.
Eighteen exact duplicate invocations are removed; source/built and worker/browser
variants remain. The final gate checks complete coverage and commit identity.
Release tags reuse the exact artifact from successful main CI instead of
repeating the suite. Per-command timing reports support further balancing.

Magic calibration profiles, original face geometry and typography are unchanged.
