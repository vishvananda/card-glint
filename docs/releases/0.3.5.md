# card-glint 0.3.5

The Magic pack now uses measured Legends frame families and shared geometry:
ABU assets for white and black, and Fourth Edition assets for the other colors,
artifacts, lands and gold cards. Frame and paper colors are calibrated separately
with texture and shadow preservation checks. Titles, type lines, mana and set
symbols use shared printing defaults fitted after scan-only frame normalization.

Legends rules use measured short, regular and compact size classes. Short
passages retain the printing's centering policy; explicit host alignment and the
chosen original or Oracle wording reference remain authoritative. All 310
printings fit in both wording modes without dropping words. Original inline
generic mana values and supplied discretionary word breaks remain reversible
when switching to modern wording and symbols.

Illustrator credits are left-aligned, include © 1994, and use their measured
size, baseline and width. Power/toughness has independent placement and shadow
settings. Both use slightly lighter solid strokes. All 70 footer candidates
match actual renderer output exactly; every reserved credit and stats example
improves its local text-edge score.

The full-set comparison improves structural match from **46.0% to 76.2%**
across 303 accepted scan poses; all 303 improve. All 310 printings render.
Both painters receive identical original wording and artwork, including the
scan-reviewed flavor-only bodies of Wall of Earth and Wall of Heat. These
fixed-region edge scores exclude color and unverified legal text. They are
similarity indices, not percentages of pixel correctness.

The comparison fixtures retain frame-normalization failures and typography
outliers. Sentinel, Fallen Angel and Dream Coat still need review for printed
wrapping, mixed alignment or spacing. Torsten Von Ursus retains a frame-source
mismatch. Scan poses are comparison metadata and never move rendered cards.

Public interfaces remain compatible. The public showcase continues to use only
original repository assets, and the cached painter adds no work to animation.
