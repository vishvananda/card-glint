# card-glint 0.4.6

This patch improves original artist credits in Arabian Nights, Antiquities and
The Dark. Public interfaces remain compatible.

- Use shared, scan-fitted credit sizes, left alignment and edge lettering.
  Include the printed `Illus. ©` prefix and The Dark's `1994` year.
- Add 19 reviewed printing-specific artist credits to `resolvePrintingArtist`,
  preserving canonical provider metadata separately.
- Correct original wording for The Dark's Carnivorous Plant and Hidden Path.
  Carnivorous Plant has no printed rules text; Hidden Path's attribution is
  inline. Oracle wording remains separate.
- Replay all 316 printings. Artist placement matches the private fitting painter
  exactly on 268 studied cards, and all pixels outside the artist region remain
  unchanged. All 189 reserved artist comparisons improve.

Rules-text size and centering trials remain provisional and are not included as
runtime defaults. The 34 unresolved scan poses remain unscored; this release
does not claim complete calibration of any set.
