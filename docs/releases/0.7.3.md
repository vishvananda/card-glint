# card-glint 0.7.3

Fixes name and type-line text appearing too low on Eighth Edition and other
frames that use its Matrix heading font.

The pinned font contains a positive descender in its horizontal and typographic
metrics. Browsers interpret its middle baseline differently: macOS placed
headings about 7–9 canonical pixels below the Linux calibration. Matrix headings
now use an explicit alphabetic baseline on every platform.

All calibrated frame, font-size and placement values remain unchanged. All 357
Linux Original card renders and their 357 etching layers are byte-identical to
the existing Eighth calibration census. macOS Original and Oracle comparisons
confirm that the correction changes only the name and type-line regions.
Chromium and WebKit regression tests cover baseline placement and Canvas state.

There are no public API changes. Existing canonical Linux calibration scores
remain reusable for matching native-image hashes; pre-fix client scores with
different rendered pixels must be regenerated.
