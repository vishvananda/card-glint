# card-glint 0.6.2

Alpha names and type lines use a shared fit verified across all 292 accepted
printing scans. The calibration editor exposes independent position, size,
width, word spacing, filled-gray ink and shadow controls for both headings.

- Names improve from 70.32 to 71.24/100 and type lines from 61.72 to 62.97/100
  on the fixed aligned development scans. These are regional structural indices,
  not whole-card scores or percentages. Some individual cards still regress;
  no reliable first-letter or per-card exception rule emerged.
- Width controls use 0.001 steps. Existing title-only profile consumers remain
  compatible; newly evaluated Alpha proposals bind to profile revision 2.
- Original artist credits follow the physical printing: Alpha's Douglas Schuler
  spelling, the reviewed Beta and Unlimited misspellings with their two correctly
  spelled exceptions, and Anson Maddocks on Alpha Circle of Protection: Red.
  Provider metadata is preserved separately.
- Numerical evidence, old/new split lists and the default-promotion replay are
  included under `games/magic/fixtures/accuracy/heading-spacing/`.

This is a compatible patch. Experimental reconstructed frames are not shipped.
Whole-card validation remains separate from the completed heading fit.
