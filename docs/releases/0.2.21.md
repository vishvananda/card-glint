# card-glint 0.2.21

Improve original-printing reproduction and make symbol calibration reusable
without rerendering and rescoring the whole card for every adjustment.

- Select historical mana artwork per set/color through Eighth Edition, while
  keeping original symbols available with Oracle wording. Preserve separate
  disc-color calibration and cache prepared glyph materials.
- Restore printed multicolor cost ordering: exact Legends/The Dark costs and
  scoped WUBRG rules for Ice Age, Chronicles and Alliances. Explicit host-supplied
  wording takes precedence. Oracle costs remain independent of symbol artwork.
- Add 129 scan-bound original artifact type reviews for Alpha, Beta and
  Unlimited to the printing-reference adapter. Restore Mono/Poly/Continuous
  labels without guessing from current abilities; Jade Statue stays Artifact.
- Add 25 validated printing-color profiles across Alpha, Beta, Revised, Eighth
  Edition and M21. Admit frame and paper independently against reserved scans,
  guard the exact source asset/geometry, and retain prior values where a fit
  fails. Coverage remains partial; see the Magic pack's five-set color report.
- Extend `symbolAdjustment.mana` with cost spacing and independent numeral
  size/x/y controls and per-color glyph size/x/y controls inside fixed discs. Cache reference and rendered regional measurements, reject
  invalid normalization, and provide full-set scan templates for the same five
  sets. Scoring tools remain separate from runtime painting.
- Correct Split/Fuse shared-panel gradients, matching-guild watermark
  inheritance and per-half tint, oval stamp size, footer baseline and small-cap
  artist text. Include 20 scan-bound INV/APC/DIS copyright transcriptions;
  synthesized legal lines elsewhere remain unverified.

Historical glyph evidence covers 51 sets/collections and 2,017 scan samples.
Contaminated crops and ambiguous matches remain explicit review flags. These
candidate and component measurements are not whole-card compliance scores.
Existing scores must be regenerated for the new renderer version.

Ordinary-card/planeswalker stamp coverage and animated holographic stamp
interiors remain queued, along with Rooms and Battles. The public showcase
continues to use only original repository assets.
