# Rejected complete type-plate replacement

Do not promote these type-paper HSB or rectangle-registration values. Enlarged
visual review found that the whole sprite replacement changed the left contour,
raised the box and its text/symbol anchors, removed the independent bottom shadow,
and introduced a hard beveled rim. Better unprinted paper RGB error did not
measure those regressions. This experiment was not released.

The accepted backgrounds are independent. The release restores the previous type
slot, paper, left edge and shadow, correcting its upper-right quadratic turn and clipping only unwanted rightward
shadow at the rim.
Current native evidence and the corner-only pixel regression test are one level up.
